# Currículo Web Single-Page | Gustavo Martins

Este repositório contém o código-fonte do meu currículo e portfólio pessoal online, construído em uma arquitetura *Single-Page Application* (SPA) estática. 

## 💻 Sobre o Projeto

O projeto foi desenvolvido como requisito avaliativo para a disciplina de **Tecnologias de Desenvolvimento para Internet III**, do 4º período do curso de Sistemas de Informação do IFSULDEMINAS - Campus Machado. 

O objetivo principal foi aplicar na prática conceitos avançados de estruturação web, dispensando o uso de frameworks CSS prontos (como Bootstrap ou Tailwind) para focar no desenvolvimento manual e aprimoramento das habilidades fundamentais de front-end.

## 🚀 Funcionalidades

- **Design Responsivo:** Layout adaptável para desktops, tablets e smartphones utilizando CSS Media Queries.
- **Navegação Fixa (Sticky Sidebar):** Menu lateral de acesso rápido que se transforma em uma barra de navegação superior em dispositivos móveis.
- **Scroll Suave (Smooth Scroll):** Transições fluidas ao navegar entre as seções pelo menu.
- **ScrollSpy Dinâmico:** Script em JavaScript Vanilla que detecta a posição da rolagem da tela e destaca automaticamente a seção ativa no menu de navegação.
- **Estrutura Semântica:** Uso rigoroso de tags HTML5 (`<main>`, `<aside>`, `<section>`, `<nav>`, `<footer>`) para melhor acessibilidade e SEO.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Flexbox, UI/UX minimalista e Media Queries)
- **JavaScript** (Lógica de interatividade do DOM)
